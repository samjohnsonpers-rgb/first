Every Gemini request goes Browser → /api/gemini → Netlify Function → Gemini API. The API key lives only in the Netlify environment variable GEMINI_API_KEY — it is never stored in, or sent from, this browser. Routing through the server also avoids the browser “User location is not supported” error.
